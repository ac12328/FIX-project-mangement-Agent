# Onboarding Milestone Guide

**Independently authored demo explanation; not operational approval.**

Use the JSON contract and verified project evidence for every stage. M1 covers network setup; M2 UAT session configuration; M3 UAT access; M4 application testing; M5 conformance cases; M6 test report and production preparation; M7 delivered production session and PCT; M8 completed onboarding. Titles describe stages, not an instruction to invent endpoints or approvals. Record evidence references, contradictions and uncertainty. Do not derive completion from typical actions or a planned date.

The executable policy owner is the versioned milestone contract. See [[concept/milestone_state_machine]].
