Read ../README.md and ../docs/PUBLIC_DEMO_POLICY.md first.
This is a preparation source snapshot, not a validated deployment. Inherited dashboard tests, captured pages and fixtures are withheld intact for independent synthetic-fixture review. No dashboard build, type check or browser test is claimed.

The demo development/start scripts bind loopback port 3317 and the API proxy defaults to loopback port 8317. Do not point them at an existing deployment or run them as part of de-identification. Standard root launchers are blocked; these npm scripts are not a sandbox. Future UI validation requires independently configured, fictional data and outbound isolation.
