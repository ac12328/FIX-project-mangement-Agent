# Query Parser

Parse the user's project portfolio query into structured filters.

Only use these fields when clearly requested:
- ball_with (internal, external, shared)
- project_status (active, blocked, waiting, completed, archived, cancelled)
- current_milestone (M1-M8)
- market (HK, US, SG, JP, CN)
- client_name (partial name match)
- search_text (free text search)

Use simple values like internal, external, active, blocked, M4, or a client name fragment.
